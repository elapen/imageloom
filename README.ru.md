# ImageLoom

**Локальная студия ИИ-изображений для Mac и Windows.**<br>
Общайтесь со своей моделью как в чате: создавайте, правьте кистью, увеличивайте до 4K, экспортируйте PNG с прозрачным фоном, WebP и SVG.<br>
Без облака, без аккаунта, без возни с Python: ничего не уходит с вашего компьютера.

## Зачем это нужно

- **Как чат, а не граф нод.** Отдельные чаты, у каждого своя модель и «усилие»; результат одного сообщения становится исходным фото для следующего («сделай ночь»).
- **Всё в одном приложении.** Создание → правка по описанию или **кистью по маске** → **апскейл ×2 / ×4 / 2K / 4K / 8K** → экспорт **PNG, WebP, JPEG, SVG** с настоящим прозрачным фоном.
- **Новая модель в день выхода.** Вставьте ссылку на Hugging Face, выберите файл: нужное докачается само и модель появится в выборе. Без YAML и скриптов.
- **Лёгкое и приватное.** Нативное окно (не вкладка браузера), ~160 МБ без моделей, один локальный сервер: стартует вместе с приложением и выключается (вместе с рендером), когда вы выходите.
- **Честные оценки времени.** Время берётся из замеров на вашем компьютере и помечается «оценка», пока модель не засекли.
- **Для людей и для агентов.** Крошечный CLI (`imageloom "красная лиса на снегу" --upscale 4k`) и готовые навыки для Claude Code, Cursor и Hermes.

## Скачать

| Платформа | Где взять | Примечания |
|---|---|---|
| **macOS** (Apple Silicon, macOS 13+) | [`ImageLoom-1.0.0-macOS-arm64.dmg`](https://github.com/elapen/imageloom/releases/latest) | Перетащите в «Программы». Приложение без нотаризации: в первый раз ПКМ → **Открыть** (или «Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть**»). |
| macOS через Homebrew | `brew install --cask elapen/tap/imageloom` | То же приложение. |
| **Windows** 10/11 x64, *экспериментально* | [`ImageLoom-1.0.0-Windows-x64-Setup.exe`](https://github.com/elapen/imageloom/releases/latest) или portable `.zip` | Собрано с macOS и **ещё не запускалось на настоящей Windows**: напишите, что получилось. SmartScreen предупредит (без подписи). Нужна видеокарта с Vulkan. |
| Из исходников (любая ОС, Python 3.9+) | `pip install -r core/requirements.txt && python3 core/server.py` | Откройте http://127.0.0.1:7870. Linux не проверялся. |

**Первый запуск.** Мастер заранее показывает, что именно будет скачано (движок, модель по умолчанию, апскейлеры) и сколько это весит. Модель по умолчанию **Qwen-Image 2.1 Turbo Q8** занимает около 18 ГБ;
**Z-Image Turbo Q4** на 4 ГБ можно добавить из меню выбора модели. После загрузки приложение работает полностью офлайн.

**Железо.** Идеально: Apple Silicon с **16 ГБ ОЗУ** (Qwen-Image занимает ~9 ГБ при создании и ~10,5 ГБ при правке). Больше памяти и мощнее чип означает просто быстрее.

## Что умеет

- **Создание** по описанию (на русском, английском и других языках, которые понимает модель), пропорции, 1–8 картинок за раз, seed, быстрые стили.
- **Правка** фото по описанию или **по маске**: закрасьте область кистью и опишите, что там должно быть. Можно добавить ещё референсы («вставь человека со второго фото в первое»).
- **Апскейл** моделями Real-ESRGAN (качество / быстро / иллюстрации) или автоматически после каждой генерации: черновик 512 px, через минуту 4K.
- **Экспорт**: PNG, WebP (с потерями или без), JPEG и **SVG** (векторная трассировка: пресеты логотип / иллюстрация / детально / чёрно-белое). Прозрачный фон настоящий, с альфа-каналом.
- **Порядок**: чаты, галерея, избранное, дерево версий каждой картинки, слайдер «до/после», «показать в Finder / Проводнике», в Корзину.
- **Уведомления** о конце долгого рендера. При выходе во время задачи приложение спросит подтверждение.
- **Языки**: интерфейс на английском и русском (определяется автоматически, переключается вручную).
- **Горячие клавиши**: `⌘K` палитра команд, `⌘N` новый чат, `/` в поле ввода, `?` справка.

## Скорость (базовый M4, 16 ГБ, одна картинка)

| | 512² | 768² | 1024² |
|---|---|---|---|
| Qwen-Image 2.1 Turbo Q8, создание | 110 с | 239 с | 395 с |
| Z-Image Turbo Q4_K, создание | 84 с | 151 с | ~250 с (оценка) |
| Qwen-Image, правка | 152 с | 20 мин (своп) | не стоит |
| Апскейл 1024² → 4096², Real-ESRGAN quality | | | 245 с |

Это ноутбук, а не RTX: диффузия на 16 ГБ общей памяти медленная, но стабильная. Лучший рабочий процесс: маленький черновик, затем апскейл удачного ([замеры](docs/BENCHMARKS.md)).

## Командная строка и ИИ-агенты

```bash
imageloom "винтажный постер Швейцарских Альп, надпись 'SWISS ALPS'" -s 768x1024
imageloom edit photo.jpg "замени небо на драматичный закат" -o edited.png
imageloom "логотип: голова лисы, плоский векторный стиль" --transparent -o fox.png
imageloom export fox.png --format svg --preset logo
imageloom upscale picture.png --to 4k
imageloom models add https://huggingface.co/leejet/Z-Image-Turbo-GGUF --dry-run
imageloom batch prompts.txt  # один JSON-результат на каждую непустую строку
```

В пакетном файле каждая строка содержит один промпт. В строку можно добавить поля `size=ШИРИНАxВЫСОТА` и `model=ID`; текст промпта также можно заключить в кавычки. Пустые строки и строки, начинающиеся с `#`, пропускаются.

CLI требует только Python 3.9+. Он общается с сервером запущенного приложения или поднимает свой. Скопируйте [`skills/imageloom`](skills/imageloom/SKILL.md) в `~/.claude/skills/` или
`~/.cursor/skills/` (вариант для Hermes: [`skills/hermes`](skills/hermes/imageloom/SKILL.md)), и ваш кодинг-агент сам сможет создавать и править картинки для проектов.

## Приватность и ответственность

- Промпты, картинки и история не покидают компьютер. Сеть используется только по вашему действию: загрузки с Hugging Face и релиз движка с GitHub. Телеметрии нет.
- Сервер слушает только `127.0.0.1` и отклоняет межсайтовые запросы. Токен Hugging Face (для закрытых репозиториев) необязателен и хранится локально.
- **В этой связке нет фильтра контента.** Текстовый энкодер модели по умолчанию это вариант Qwen3-VL с убранными отказами, а у диффузионных моделей собственного фильтра нет. Вы отвечаете за то, что создаёте и публикуете:
  не делайте незаконный контент, сексуальный контент с участием несовершеннолетних и реалистичные изображения реальных людей без их согласия. На результаты распространяются лицензии моделей
  (веса Qwen по умолчанию только для исследований и некоммерческого использования), см. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
